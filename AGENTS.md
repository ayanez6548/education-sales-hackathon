# Project conventions

- This is a standalone hackathon project. Keep all source, configuration, tests, and documentation in this repository.
- Use American English for identifiers, source filenames, comments, docstrings, test descriptions, and developer logs.
- Keep all user-facing application text, bot messages, validation, tooltips, and accessibility text in Spanish.
- Keep student-facing explanations, README, demo, deployment, and defense documentation in Spanish.
- Never commit secrets, local environment files, virtual environments, dependency directories, database data, or generated logs.
- Implement the requirements in SPEC_HACKATHON.md. Clearly distinguish simulation from live integrations.
- Do not change files outside this project.
